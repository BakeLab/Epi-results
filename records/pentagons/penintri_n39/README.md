# Pentagons in a triangle: penintri_n39

Minimize the side of an equilateral triangle containing non-overlapping regular pentagons of side one.

| Reference | Épi | Direction |
| :-- | :-- | :-- |
| 13.9843149695291 | **13.9752132053161** | Lower is better |

Angles are in radians. The numerical non-overlap check uses a penetration tolerance of 10⁻¹² in units of pentagon side length. The reference column uses the recorded comparison value; several earlier cases use remeasured published constructions.
