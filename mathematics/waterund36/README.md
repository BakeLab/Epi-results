# Water-network design: waterund36

| Quantity | Published comparison | Épi |
| :-- | :-- | :-- |
| Water-network design, waterund36 | 655.5441707 (MINLPLib) | **662.80702839** |

The original continuous waterund36 minimization instance, with 324 variables and 239 constraints.

Exact support-chain certificate excludes the stated objective cutoff for a relaxation containing the original feasible set. The final lower bound is rounded downward.

The known feasible value is 662.8070384, leaving a gap of about 0.00001001. Castro’s No-sBB result implies a lower bound around 655.79 from its rounded gap; Épi also improves that bound. The result tightens the global lower bound.
