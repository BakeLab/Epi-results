# Cap-body illumination

Seven improved upper bounds on illumination numbers, in dimensions 9 through 15 respectively.

| Reference | Épi |
| :-- | :-- |
| 103, 157, 236, 353, 520, 769, 1127 | **102, 154, 233, 347, 514, 757, 1110** |

## Final artifacts

The final discretized coefficients for each dimension. The dual inequalities hold in rational arithmetic for these coefficients.
